# Installation

## Stable release

To install MRMU Validation Suite, run this command in your terminal:

```sh
uv add validation-suite
```

Or if you prefer to use `pip`:

```sh
pip install validation-suite
```

## From source

The source files for MRMU Validation Suite can be downloaded from the [Github repo](https://github.com/ccsarmientot/validation-suite).

You can either clone the public repository:

```sh
git clone https://github.com/ccsarmientot/validation-suite
```

Or download the [tarball](https://github.com/ccsarmientot/validation-suite/tarball/main):

```sh
curl -OJL https://github.com/ccsarmientot/validation-suite/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd validation-suite
uv sync
```
